## 上传步骤

1. 打开 B 站创作中心 → 投稿 → 视频投稿；
2. 上传 `columbina-promo.mp4`；
3. 封面选 `bilibili-cover.png`；
4. 标题、简介、标签照上面填；
5. 分区选「科技 → 软件应用」；
6. 勾选自制；发布前再确认一遍简介里的 GitHub 链接与素材声明。

- 视频里含角色美术、开屏影片与三首 HOYO-MiX 的摇篮曲；公开传播前请确认素材授权范围。
- B 站有版权识别，摇篮曲段落可能被静音或限流；介意的话把 20s 之后的部分静音再传。
- 如果平台对「原神」相关二创有额外要求，按平台规则补充说明。
